 # PharmaConnect Documentation
 
 Welcome to the PharmaConnect documentation set. This folder captures the architecture, APIs, data model, frontend, scraper, developer workflows, and operations guidance for the project.
 
 ## Contents
 - [`architecture.md`](architecture.md) — system context, components, and how frontend, backend, DB, and scraper interact.
 - [`backend.md`](backend.md) — Spring Boot structure, layers, patterns, security, and internal services.
 - [`api.md`](api.md) — REST endpoints, DTOs, and key flows (items, cart, orders, pharmacies, chatbot, map).
 - [`data.md`](data.md) — database schema, Flyway migrations, seed data, and translation support.
 - [`frontend.md`](frontend.md) — React/Vite app structure, routing, UI libraries, i18n, and user journeys.
 - [`scraper.md`](scraper.md) — data scraping pipeline, providers, and product configuration.
 - [`dev-setup.md`](dev-setup.md) — local setup, environment, running services, lint/build, Docker.
 - [`testing-ops.md`](testing-ops.md) — testing status, manual checks, logging/monitoring, deployment considerations.
 - [`master-export.md`](master-export.md) — single-file consolidation for PDF/Word export.
 
 ## Audience and scope
 - New contributors who need a project overview and setup steps.
 - Reviewers who need to understand architecture, API surface, and data flows.
 - Operations/QA who need running, testing, and deployment guidance.
 
 ## How to use
 - Start with `architecture.md` for the big picture, then dive into backend/frontend/API/data as needed.
 - Use `master-export.md` when you need a one-stop document to print or convert to PDF.
